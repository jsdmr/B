# Музей изобразительных искусств

Полноценный сайт музея, реализованный на PHP/MySQL с адаптивным интерфейсом, страницами коллекций и кастомным плагином Random Line.

## Структура
- `index.php` — главная слайдер, блок «О музее», интересные экспонаты, контакты, форма заявки и карта.
- `exhibits.php` — все экспонаты с фильтрацией по категориям и пагинацией.
- `exhibit.php` — карточка экспоната с подробным описанием, галереей и внешними ссылками.
- `partners.php`, `salon.php`, `visitors.php` — дополнительные страницы меню.
- `includes/` — подключение к БД (`db.php`) и вспомогательные функции (`functions.php`).
- `assets/` — стили и скрипты, в том числе Swiper для слайдера.
- `plugins/random-line/` — плагин Random Line, который выводит факты поверх страницы при прокрутке.
- `database.sql` — схема таблиц и тестовые данные.

## Развёртывание
1. Создайте базу данных `museum` (или задайте собственные значения через переменные окружения `MYSQL_HOST`, `MYSQL_DATABASE`, `MYSQL_USER`, `MYSQL_PASSWORD`).
2. Выполните SQL-скрипт `database.sql`.
3. Разместите проект в директории веб-сервера и убедитесь, что PHP имеет доступ к PDO MySQL.

## Плагин Random Line
- Настройки находятся в `plugins/random-line/settings.php` (ID поста-источника и интервал появления).
- Содержимое фактов берётся из таблицы `facts_posts`. Каждая строка текста будет потенциально показана пользователю.
- Плагин автоматически подключается внизу всех страниц (см. `include` перед закрывающим `</body>`).

## Форма заявок
Форма на главной странице сохраняет данные в таблицу `visit_requests`. Для отправки писем можно расширить функцию `saveVisitRequest`.

## Зависимости
- [Swiper](https://swiperjs.com/) — слайдер главной страницы.
- [Font Awesome](https://fontawesome.com/) — иконки социальных сетей в футере.
